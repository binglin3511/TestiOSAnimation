# TearEffectDemo 使用指南

## 快速开始

### 1. 打开项目
使用Xcode打开 `TearEffectDemo.xcodeproj` 文件

### 2. 运行项目
- 选择iOS模拟器（推荐iPhone 14 Pro或更新）
- 点击运行按钮（⌘R）

### 3. 测试撕裂效果
1. 点击屏幕底部的"撕裂动效"按钮
2. 从弹出的菜单中选择一种撕裂效果
3. 在效果页面点击"开始撕裂"按钮观看动画

## UE参数调整指南

所有可调参数都标记为 `【UE参数】`，可以在以下文件中找到：

### Perlin噪声撕裂 (PerlinNoiseTearViewController.m)

```objective-c
// 第59-66行
self.waveAmplitude = 15.0;  // 波浪振幅（锯齿高度）
self.waveCount = 50;        // 波浪数量（锯齿密度）
self.noiseScale = 1.0;      // 噪声缩放因子
```

**调整建议：**
- 增大 `waveAmplitude` 会让锯齿更明显
- 增大 `waveCount` 会让锯齿更密集
- 增大 `noiseScale` 会让撕裂边缘更随机

### 分层撕裂 (LayeredTearViewController.m)

```objective-c
// 第53-61行
self.jaggedHeight = 25.0;   // 锯齿高度
self.jaggedWidth = 20.0;    // 锯齿宽度
self.jaggedCount = 20;      // 锯齿数量
```

**调整建议：**
- 增大 `jaggedHeight` 会让锯齿更深
- 增大 `jaggedCount` 会让锯齿更多更密集
- 可以调整第174行的 `i % 2` 逻辑来改变锯齿方向

### ShapeLayer遮罩撕裂 (ShapeLayerTearViewController.m)

```objective-c
// 第52-61行
self.irregularityFactor = 0.8;    // 不规则程度
self.controlPointCount = 30;      // 控制点数量
self.maxDeviation = 40.0;         // 最大偏离距离
```

**调整建议：**
- 增大 `irregularityFactor` 会让撕裂边缘更不规则
- 增大 `controlPointCount` 会让撕裂路径更复杂
- 增大 `maxDeviation` 会让撕裂边缘偏离中心更远

## 动画参数调整

所有三个效果都有以下可调参数：

### 动画持续时间
在每个ViewController的 `startTearAnimation` 方法中：

```objective-c
dispatch_after(dispatch_time(DISPATCH_TIME_NOW, (int64_t)(1.5 * NSEC_PER_SEC)), ...
```

修改 `1.5` 为其他值（单位：秒）

### 撕裂速度
在每个ViewController的 `updateAnimation` 方法中：

```objective-c
self.tearProgress += 0.015;  // 每帧增加的进度
```

增大这个值会让撕裂更快，减小会让撕裂更慢

## 自定义图片

### 方法1：使用自己的图片资源

1. 将图片添加到项目的Assets.xcassets
2. 在各个ViewController中替换图片加载代码：

```objective-c
// 原代码
self.topImageView.image = [self createGradientImageWithSize:bounds.size ...];

// 替换为
self.topImageView.image = [UIImage imageNamed:@"your_top_image"];
self.bottomImageView.image = [UIImage imageNamed:@"your_bottom_image"];
```

### 方法2：修改渐变色

修改 `createGradientImageWithSize:startColor:endColor:` 的调用参数：

```objective-c
[self createGradientImageWithSize:bounds.size
                       startColor:[UIColor colorWithRed:0.2 green:0.6 blue:0.9 alpha:1.0]
                         endColor:[UIColor colorWithRed:0.5 green:0.2 blue:0.8 alpha:1.0]];
```

## 常见问题

### Q: 如何让撕裂效果循环播放？
A: 在 `updateAnimation` 方法中，当 `tearProgress >= 1.0` 时，重置为 0 而不是停止。

### Q: 如何改变撕裂方向？
A: 修改各个ViewController中计算撕裂宽度的逻辑，例如从上到下撕裂而不是从中心向两边。

### Q: 如何添加声音效果？
A: 使用 `AVFoundation` 框架，在 `startTearAnimation` 方法中播放音效：

```objective-c
#import <AVFoundation/AVFoundation.h>

SystemSoundID soundID;
NSString *soundPath = [[NSBundle mainBundle] pathForResource:@"tear" ofType:@"wav"];
AudioServicesCreateSystemSoundID((__bridge CFURLRef)[NSURL fileURLWithPath:soundPath], &soundID);
AudioServicesPlaySystemSound(soundID);
```

### Q: 如何让撕裂效果更流畅？
A: 增加 `controlPointCount`（ShapeLayer遮罩撕裂）或 `waveCount`（Perlin噪声撕裂）的值。

## 性能优化建议

1. 如果在真机上运行卡顿，可以减少控制点数量
2. 避免在动画过程中进行大量计算
3. 使用 Instruments 的 Time Profiler 分析性能瓶颈

3. 项目编译设置是否正确
